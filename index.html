        FAQ

        Answers to the questions that come up most often.

        My pay looks wrong

        Start with Handshake's guide to how AI payments are processed:

        Handshake AI payments processing

        For Ivy and Roadhouse, a task counts once it reaches Ready to Deliver or Delivered. Review stages, Awaiting Review, Needs Fixing, and staging are still in the review loop.

        For Jet, this dashboard adds $10 per hour from Handshake's tracked task time. It adds another $220 when a task reaches Ready to Deliver or Delivered.

        The dashboard is an estimate. The Handshake Payments page is the final source of truth.

        How do I know if a task is RTD or Delivered?

        This dashboard pulls the exact stage from your Handshake task list and shows it beside each task.

        On the HAI task page, you can also hover over the task ID in the top-left. Unknown can still mean RTD or Delivered after you hover, so check the hover text before assuming it is stuck.

        When are new tasks coming?

        Tasks come in batches, and there is not a fixed daily schedule. This dashboard checks each queue every minute and can notify you when a batch appears.

        My task says Needs Fixing but I don't see feedback

        Check your task tab first. Select the task, click View, and look for feedback on the right side. If nothing shows there, check the most recent sheet that was sent by the team.

        If the task still has no feedback, the feedback looks stale, or the task ID is missing from the sheet, ask in ivy-online-ranking-tasking with the task ID and what you checked.
